# Contributing to Ashutool

Ashutool is made by Ashutosh Nishad (Telegram @ashutosh_07x). Fixes and ideas are welcome.

1. Open an issue first for big changes, or ask on Telegram.
2. Keep the code style of the project: Kotlin, Jetpack Compose, short comments that say why.
3. Every source file starts with the header you see in the other files. Keep it. Do not remove or change the
   author credit. That is required by the licence, see NOTICE.
4. Test on a rooted device. Say which phone and Android version in the pull request.
5. By sending a pull request you agree that your change is shared under the same licence, GNU GPL v3.0 or later.

Bug reports: open the app, go to Settings, About, tap Copy debug info (and Copy last crash if there was one)
and paste it into the issue.
